# Kanban Board

A simple Kanban board built with HTML, CSS and JavaScript.

## Features

- 4 columns: Backlog, To Do, In Progress, Done
- Create, edit and delete cards
- Drag and drop cards between columns
- Priority tags (High, Medium, Low)
- Persist tasks using a backend (json-server / Firebase)
- Responsive design

## Technologies

- HTML5
- CSS3
- JavaScript
- json-server / Firebase (for data persistence)

## What I Learned

- Structuring semantic, reusable HTML with shared classes
- Working with Flexbox for layout (main axis vs cross axis, stretch behavior)
- DOM manipulation and dynamic rendering from data
- Handling CRUD operations against a backend/API
- Using the native HTML5 Drag and Drop API
- Managing more complex, nested application state
- Git workflow with feature branches and pull requests

## How to Use

1. View tasks organized across the four columns.
2. Click "+ New" to add a card to a column.
3. Drag a card to move it between columns.
4. Click a card to edit or delete it.

## Design Inspiration

Inspired by a Kanban board UI concept found on Behance. The layout and visual design were recreated as a learning exercise, with all HTML, CSS, and JavaScript functionality implemented independently.
